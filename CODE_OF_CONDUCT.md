# Code of conduct

Haris follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:

- **Be kind and assume good faith.** People here write in English, Arabic, or both, and many in a
  second language. Help them; don't correct them for sport.
- **Criticise ideas, not people.** Hard questions about the security design are welcome. That is the
  point of the project.
- **No harassment.** No insults, slurs, sexual content, personal attacks or threats, and no
  publishing someone's private information.
- **Respect "no".** If someone asks you to stop, stop.

These rules apply in issues, pull requests, discussions and anywhere you represent the project.

## Reporting

Send the maintainer, Mahmoud Farouk, a private message on
[LinkedIn](https://www.linkedin.com/in/mahmoud-farouk-abdelhamid). Reports are read privately and
handled fairly. The maintainer may edit or remove comments, close threads, or block people who
break these rules.

Security vulnerabilities are different: report them through [SECURITY.md](SECURITY.md).
